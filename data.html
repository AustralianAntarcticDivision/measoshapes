Data

Files, stable URLs, and what’s in them

Files

The regions are published at stable URLs under

https://australianantarcticdivision.github.io/measoshapes/data/v06/

The same files are in the R package, in inst/extdata (find them with system.file("extdata", package = "measoshapes")), and are created by data-raw/export.R.

and a QGIS style, measo_regions06.qml (see QGIS).

Which to use:

  • Polar equal area (measo_regions06.*): areas, maps of the Southern Ocean, overlays with polar data.
  • Longitude/latitude (measo_regions06_ll.*): assigning regions to longitude/latitude data, web maps. Boundaries are straight in longitude/latitude (see Definition).
  • EPSG:3031 (measo_regions06_epsg_3031.*): polar stereographic maps, e.g. Quantarctica. Not equal area.
  • GeoParquet for data tools (R, Python, DuckDB, the browser); FlatGeobuf for GIS and streaming; GeoJSON for simple web maps.

Columns

  • name: region code, sector code then zone code (T for the temperate regions).
  • label: full name, zone then sector, e.g. “Antarctic Atlantic”.
  • sector: one of Atlantic, CentralIndian, EastIndian, WestPacific, EastPacific.
  • zone: Antarctic, Subantarctic, Northern; empty for the T regions (outside MEASO).
  • fill: the region’s colour in the MEASO Summary for Policymakers (Figure 5), as #RRGGBB; empty for the T regions.

Versions

The v06 in the URL is the version of the regions. Version 06 has the boundaries of version 05, with one row per region, labels, and the published colours; see Definition and News. Version 05 is available in the R package as released (measo_regions05), and as the geopackages in inst/extdata.
